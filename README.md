## 🌷 Descripció

Aquest projecte és un petit sistema **TPV** desenvolupat en **Java**, pensat per simular la gestió bàsica d’una botiga de roba.

L’aplicació treballa amb articles com **camises** i **pantalons**, utilitza una base de dades **MySQL** i deixa preparada una estructura clara per gestionar productes, clients, tiquets i vendes.

Encara és una versió inicial, però ja té una base ordenada per continuar afegint funcionalitats sense que el projecte es converteixi en un caos amb potes. 🐾

---

## ✨ Funcionalitats

- 🌸 Connexió amb MySQL
- 👕 Gestió inicial d’articles
- 🧾 Script SQL per crear la base de dades
- 📦 Fitxer JSON amb dades de prova
- 🧩 Classes per organitzar el model del projecte
